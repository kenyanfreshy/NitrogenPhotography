# Nitrogen Studios

Website and installable phone web app for Nitrogen Studios, an award-winning photography, videography, drone and livestream studio in Salgaa, Kenya.

- `index.html`: the whole site (no build step)
- `img/`: portfolio photographs
- `icons/`, `manifest.webmanifest`, `sw.js`: phone app (install to home screen, offline viewing)
- `netlify.toml`: Netlify publish settings
